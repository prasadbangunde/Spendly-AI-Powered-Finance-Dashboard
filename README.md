# Spendly

Spendly is a personal finance management application that helps users track expenses, manage budgets, and gain insights into spending habits.

## Features
- Expense Tracking
- Budget Management
- Spending Analytics
- User Authentication
- Responsive UI

## Tech Stack
- Frontend: React.js
- Backend: Node.js / Express
- Database: MongoDB
- Authentication: JWT

## Installation

```bash
npm install
npm start
